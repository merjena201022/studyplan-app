# 🌿 Study Planner 2026
## 📝 Description
This is a task management web application built with Flask. It helps students keep track of their study goals with a clean, nature-inspired green design. 
## ✨ Key Features
- **User Authentication:** Sign up and Log in to access your personal dashboard.
- **Task Management:** Add tasks with titles, notes, and deadlines.
- **Prioritization:** Mark tasks as High, Medium, or Low priority.
- **Status Tracking:** Mark tasks as complete or delete them when finished.
## 🛠 Technologies Used
- **Backend:** Python 3.x, Flask
- **Frontend:** HTML5, CSS3 (Custom Green Theme)
- **Database:** Local JSON files (`data.json`, `users.json`)
